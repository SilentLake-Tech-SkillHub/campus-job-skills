# 当前修复记录

## 2.1.7 · C9 组件维护授权来源与防重放

- 普通授权使用宿主UserPromptSubmit和真实会话ID。明确的非用户来源、通用工具结果和缺失会话ID不能生成授权。
- Codex异步卡片在宿主会话记录中核对同一会话、工作区、原始调用ID、问题位置与标题。卡片防重放标记和最近授权写入同一文件，保留加锁、原子替换、保存后读回。撤回清除有效授权，仍阻止同一卡片复用。
- Claude Code / DSH 的普通聊天沿用原入口。结构化工具答复需以宿主可核实的真实答复来源为接入依据。DSH旧桥接传入的普通消息仍依赖宿主提供正确的用户事件。
- 验收包含普通回复、同会话放行、跨会话、来源错误、请求过期、重复答复和撤回后重放。真实宿主卡片验收按工作区任务单记录。
