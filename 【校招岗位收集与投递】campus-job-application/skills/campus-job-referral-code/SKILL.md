# 内推码查询

中国大陆不少公司的校招内推码能让简历进入员工推荐通道，但网上流传的码混杂着往届、过期、其他岗位类别的帖子。本子Skill在每家公司准备投递之前先查一次，只留下能证明适用于当前批次的码，并把结果写进岗位主账本，后面填表直接取用。

先加载[父Skill](../../SKILL.md)和工作簿约定 [workbook-schema](../../references/workbook-schema.md)。目标届别、批次范围和工作簿路径从工作区的求职配置读取，不写进本Skill。

## 何时调用

- 中国大陆批次进入一家新公司、打开申请表之前。
- 用户提到内推码，或申请表出现“内推码 / 推荐码 / 内推人”字段。
- 同一公司已有本批次核实过的码时直接复用，不重复搜索；码标注了截止日期且已过期时重新查。

香港、海外等其他地区默认不调用，除非用户明确要求。

## 搜索顺序

1. **牛客（默认）**：用新标签页打开 `https://www.nowcoder.com/search?query=<公司>%20<届别>%20内推码` 或站内搜索，优先看讨论区/内推版块最近发布的帖子。正在填写的申请表页不得被导航，搜索始终另开标签页并显式指定标签页。
2. **公司官方渠道**：官方校招站或公众号公布的内推/推荐码页面。官方来源与牛客冲突时以官方为准。
3. **其他公开渠道**（只有前两者都没有结果时）：如公开的求职社区帖子。需要登录、加群、私信或付费才能拿到的码不使用。

每家公司看前若干条相关结果即可，找到一条完整核实的就停；不要为同一家公司无限翻页。

## 核实条件（全部满足才写入）

- 帖子明确写了**公司名**（或其校招品牌），且与要投的公司/招聘主体一致；子公司或独立招聘的业务线要分开看。
- 帖子明确写了**届别或批次**（如“20XX届校招”“秋招”），与当前批次一致。只写“校招”而无届别、发布时间又在当前招聘季之前的，视为未核实。
- 帖子发布于当前招聘季内；如写了有效期或适用岗位类别，记录下来并确认覆盖要投的岗位。
- 码的原文逐字抄录（区分大小写），不拼凑、不推测、不改写。

不满足时写 `未找到` 或 `未核实`，并在备注里说明看过哪些来源。宁可留空，也不能用往届码或编造的码。

## 写入岗位主账本

在该公司所有相关岗位行的 `内推码` 列写同一内容，格式固定：

```
<码>｜<来源平台>｜<届别/批次>｜<核实日期 YYYY-MM-DD>｜<来源链接>
```

未找到时写：`未找到｜<已查来源>｜<核实日期>`。写入前按父Skill的规则备份、只改受影响行，保存后读回该列。

## 投递时使用

- 申请表有内推码字段：填入账本里的码，并核对字段读回；同时有“招聘信息来源”类选项时，按实际情况选择员工内推一类的选项。
- 申请表没有该字段：不另找地方填写，在投递记录里注明“表单无内推码字段”。
- 不替用户联系内推人、不私信、不加群；需要这些动作时告诉用户由其决定。
- 内推码只影响推荐渠道，不改变父Skill及投递Skill的提交前确认门禁。

## 返回

向父Skill返回：公司、结果（已核实 / 未找到 / 未核实）、码、来源链接、届别依据和核实日期。
