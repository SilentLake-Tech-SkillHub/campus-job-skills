# 浏览器标签保留与Chrome窗口分组

默认使用内置浏览器；用户明确选择Chrome时，下方每窗口10页规则才生效。该规则不能用于改换浏览器，也不能假设内置浏览器具有Chrome窗口接口。内置浏览器按实际支持的标签能力分组，并用工具文档规定的可见保留机制交接；操作后读回公司与URL。准备/投递批次保留整组未完成页、账号页、表单及回执，未经另行明确授权不关闭。

同一个 Agent 创建的 Chrome 窗口最多打开10个网页标签页；第11个网页在新建的 Agent 窗口中打开，再按每10页一组继续。计数按当前窗口实际标签页，不按公司数；列表、岗位详情、登录、表单、研究页均占一个标签。现有页面内导航和刷新不增加计数，已有公司页优先复用，不为分组重复打开。当前窗口不足10页时继续开新标签；达到10页后先创建新窗口，再打开下一页。

只打开当前已确认范围需要的网页。10是浏览器窗口分组数，不是公司总量、业务目标、投递名额或补位规则；不足10页不为凑数加入公司，当前步骤结束后不自行扩组。用户改变本轮窗口数量时按明确的新值执行并记录；真实工具容量不足时说明实际阻塞。

- 一个窗口可以包含多家公司；每个标签记录公司、windowId/tabId、实际URL、阶段与下一步。操作前重新核对URL和公司，不能把某公司的既有标签导航成另一家公司，也不能占用用户原有窗口。新窗口必须通过执行平台支持的正常界面创建。
- 登录、未保存表单、草稿、待审核页面、回执及用户指定保留页继续保护。窗口满了只新增窗口，不关闭、移动或重载这些页面来腾位置；旧窗口及登录会话保持。
- 公司处理结束只清理属于该公司、已符合业务读回门禁的非保护Agent标签。共享窗口中的其他公司页面继续保留；只有确认整个窗口均为本Agent可关闭页面且无保护项，才能关闭整窗。准备投递的公司页仍按明确关闭授权处理，用户页或归属不清页不得关闭。
- 操作通道不能创建所需窗口或不能核对窗口归属时，记录具体阻塞，不使用用户现有窗口代替，不绕过浏览器策略。
